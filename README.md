## MOD-W — Moderated AI Development Workflow

I created [**MOD-W**](https://github.com/fpmcguire/mod-w), an open-source methodology for using AI tools in real codebases without sacrificing quality or engineering discipline.

MOD-W is role-driven and artifact-centered: changes move through explicit product, architecture, implementation, review, and validation stages, with human authority retained at the decision gates.

Planning, implementation, and validation can be performed by different AI roles and models so that one agent's assumptions do not propagate unchecked through the entire development process. Automated linting, type checks, unit tests, and E2E tests provide additional quality gates.

I use MOD-W to build my own projects and as a practical environment for exploring a broader question:

> **How much of an AI-assisted engineering system's capability comes from the model itself, and how much comes from the way models, humans, specifications, evidence, constraints, and feedback loops are orchestrated?**

**Viable coding, not vibe coding.**

## CAV — Continuous Alignment Verification

I'm developing [**Continuous Alignment Verification (CAV)**](https://github.com/fpmcguire/continuous-alignment-verification), an open, domain-agnostic methodology for determining whether evolving systems remain behaviorally aligned.

CAV starts from a simple observation:

> **A system can be healthy without being aligned.**

Traditional monitoring can tell us that individual components are running. CAV asks whether the parts of an evolving system are **still behaving coherently together** — and, when explicit intent exists, whether observed reality remains aligned with what the system is supposed to do.

The CAV maturity model progresses through:

**Observed Truth → Observed Divergence → Multi-Dimensional Alignment → Declared Intention → Formal Delta → Drift Velocity → Convergence**

CAV does not propose a new anomaly- or drift-detection algorithm. It provides a common alignment-verification model connecting concerns found in observability, concept drift, runtime verification, process conformance, continuous assurance, and reconciliation/control systems.

The project includes the **CAV Manifesto v1.0**, research foundations and prior-art analysis, a Levels 0–6 maturity model, and ongoing research into attribution as an orthogonal capability.

CAV is being explored through practical reference projects including **MQTT-Align**, **Bio-Align**, and **IDP-Align** across industrial/data-stream and enterprise workflow domains.
